GitHub Pages 업로드 방법
1. GitHub에서 새 저장소를 만듭니다.
   추천 이름: bmx-line-guide
2. ZIP을 풀고 안의 파일 3개를 저장소 최상단에 업로드합니다.
   - index.html
   - style.css
   - bmx-line.gif
3. GitHub 저장소의 Settings > Pages로 이동합니다.
4. Branch를 main / root 로 선택하고 Save 합니다.
5. 잠시 후 아래와 같은 주소로 여러 명이 동시에 볼 수 있습니다.
   https://사용자아이디.github.io/bmx-line-guide/

영상 파일 재생 대신 GIF 애니메이션을 웹페이지에서 직접 보여주므로
아이폰/갤럭시에서 별도 영상 재생 문제를 줄인 버전입니다.
